# Solar
Minecraft, but in — a lean, browser-first homage to blocky exploration.

Solar is a tiny, opinionated take on voxel play: a single-page HTML experience that runs in any modern browser. No installs, no engines — just HTML, a splash of JS/CSS, and good vibes.

Why you'll like it
- Fast to open: double-click `index.html` and you’re in.
- Delightfully minimal: focuses on the feel of exploration and building without the bloat.
- Great for demos, learning, or customizing into your own micro-world.

Quick start
1. Clone or download the repo.
2. Open `index.html` in a web browser (Chrome/Firefox/Edge/Safari).
3. Play!

Controls (default)
- Movement: WASD or arrow keys
- Look / Camera: mouse
- Jump / Action: Space
- Quick tips: hover over UI hints for extra controls

Features
- Browser-native voxel visuals (no heavy dependencies)
- Simple block placement & removal
- Lightweight performance for both desktop and mobile

Want to contribute?
- Fork the repo and open a pull request.
- Small, focused PRs are welcome — bug fixes, performance tweaks, UI polish, and new block types.
- Prefer issues for feature discussions or major changes.

Development notes
- This repo is pure HTML (static). Serve with any static host or open locally.
- If you edit scripts or assets, test in an incognito window to avoid cached JS/CSS surprises.
